# i3 Configuration

Read this before changing keybinds, workspaces, gaps, or autostart.

Repo file: `.config/i3/config` → `~/.config/i3/config` via `install/config/dotfiles.sh`.

## Keybinds (Omarchy parity, Super=Mod4)

| Keys | Action |
|------|--------|
| Super+Return | terminal (alacritty) |
| Super+Shift+Return | browser (firefox) |
| Super+Shift+F | file manager (thunar) |
| Super+Space | launcer (rofi drun) |
| Super+Alt+Space | central menu (`menu.sh` root) |
| Super+Escape | system menu (lock/suspend/logout/reboot) |
| **Super+A** | **agent** (`arch-agent`, see SKILL.md) |
| **Super+Shift+Ctrl+A** | **agent picker** (`arch-agent --pick`) |
| Super+W | close window |
| Super+J / T / F | split toggle / float toggle / fullscreen |
| Super+arrows | focus |
| Super+Shift+arrows | swap windows (Omarchy style) |
| Super+Tab / Shift+Tab | next/prev workspace |
| Super+1..9 | switch ws; Super+Shift+1..9 move to ws |
| Print / Shift+Print / Super+Print | screenshot full / region |
| Alt+Print | screenrecord (ffmpeg → ~/Videos) |
| Super+Ctrl+Print / Shift+Print | OCR (tesseract) / color picker (xcolor) |
| XF86Audio*/Brightness/Media | pamixer / brightnessctl / playerctl |

Full table: `docs/KEYBINDS.md` (and `menu.sh` Learn).

## Editing

```i3
bindsym $mod+Shift+d exec rofi -show drun
```

After edit: `i3-msg reload`. Validate: `i3 -C -c ~/.config/i3/config && echo ok`.

If rebinding an existing key, replace the old `bindsym` line — don't duplicate.

## Gaps / Colors / Autostart

- Gaps: `gaps inner 4` + `smart_gaps on` (i3 >=4.22, package `i3-wm`).
- Colors: monochrome dark `$bg #1a1a1a` etc — see config header.
- Bar: `bar { mode invisible }` — polybar is the only bar.
- Autostart (exec): polybar launch.sh, feh/xsetroot, dunst, nm-applet, udiskie, xss-lock, clipmenud, `xset r rate 250 40`.

## Window Rules

Floating TUIs: `for_window [class="^pkg$"] floating enable, resize set 900 600, move position center`.

Agent windows: `for_window [class="^agent$"] floating enable` is pre-wired if you want overlay agents (optional).
