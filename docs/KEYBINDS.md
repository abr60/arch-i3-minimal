# KEYBINDS — full reference (Super = Mod4 = Windows key)

| Keys | Action |
|------|--------|
| Super+Enter | terminal (alacritty) |
| Super+R | launcher (rofi drun) |
| Super+L | lock (i3lock solid #1a1a1a) |
| Super+Shift+Q | kill focused window |
| Super+Shift+E | exit i3 |
| Super+Shift+C | reload i3 config |
| Super+Shift+R | restart i3 |
| Super+1..9 | switch workspace 1-9 |
| Super+Shift+1..9 | move container to workspace |
| Super+Left/Down/Up/Right | focus split |
| Super+Shift+Left/Down/Up/Right | move container |
| Super+H / V | split horizontal / vertical |
| Super+F | fullscreen toggle |
| Super+S / W / E | layout stacking / tabbed / toggle split |
| Super+Space | floating toggle |
| Super+Shift+Space | focus mode toggle |
| Print | fullscreen screenshot (maim -> ~/Pictures/) |
| Shift+Print | select-area screenshot |
| XF86AudioRaise/Lower/Mute | pamixer volume |
| XF86AudioMicMute | pamixer mic |
| XF86MonBrightnessUp/Down | brightnessctl +/-5% |
| XF86AudioPlay/Next/Prev | playerctl |

Screenshots land in ~/Pictures/ (setup.sh creates it).
